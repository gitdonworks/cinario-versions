# Cinario

Un traitement de texte de scénario, avec un co-auteur dedans.

Ce dépôt ne contient que l'application prête à installer. Chaque version est
dans **Releases**, à droite de cette page.

## Avant d'installer

- Un Mac.
- Un abonnement Claude (Pro ou Max), et Claude Code installé et connecté.
  Cinario écrit avec votre abonnement ; l'accueil vérifie la connexion.

## Installer

1. Ouvrez **Releases** et prenez la dernière version :
   - `Cinario-…-arm64.dmg` pour un Mac Apple (puce M1, M2, M3, M4…) ;
   - `Cinario-….dmg` pour un Mac Intel.

   Pour savoir lequel : menu  › À propos de ce Mac. « Puce Apple » : le
   premier ; « Processeur Intel » : le second.
2. Ouvrez le fichier téléchargé et glissez **Cinario** dans **Applications**.

## Le premier lancement (une seule fois)

Cinario n'est pas encore signé par Apple : macOS le bloque la première fois.

1. Ouvrez Cinario depuis Applications. macOS dit qu'il n'a pas pu vérifier
   l'app : cliquez **Terminé**.
2. Ouvrez **Réglages Système › Confidentialité et sécurité**, descendez tout
   en bas : « Cinario a été bloqué… ». Cliquez **Ouvrir quand même**, puis
   confirmez avec votre mot de passe.
3. Cinario s'ouvre. Les fois suivantes, il s'ouvre normalement.

## Ensuite

- **Les mises à jour se font toutes seules** : quand une version sort, Cinario
  la propose à l'ouverture, un clic, et il se rouvre à jour.
- **Vos films restent sur votre Mac**, dans le dossier *Films* de votre
  dossier personnel. Une mise à jour n'y touche jamais.
